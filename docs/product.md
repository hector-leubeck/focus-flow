# FocusFlow

FocusFlow is a personal productivity dashboard.

The application combines task management, focus sessions, and productivity analytics in a single interface.

## Core experience

The main screen contains:

- application navigation
- productivity overview
- Kanban task board
- focus timer
- productivity analytics

## Task statuses

Tasks can be:

- Backlog
- In Progress
- Completed

Each task may contain:

- title
- description
- priority
- tags
- due date
- creation date

Tasks can be reordered and moved between columns using drag and drop.

## Focus timer

Users can start timed focus sessions.

The timer supports:

- start
- pause
- resume
- reset

Completed focus sessions contribute to productivity analytics.

## Analytics

Display useful information derived from application activity, including:

- tasks completed
- focus time
- completion rate
- recent productivity

## Persistence

Application data persists locally.

No account or backend is required for the MVP.
